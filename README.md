# Suryakiran Mali — Portfolio

> Personal portfolio of Suryakiran Mali, Founder & AI Creative Director at Ayrus Creatives.

**Live:** [Deploy on Render](#deploying-to-render)

## Stack

- **Backend:** Node.js + Express
- **Templating:** EJS
- **Styling:** Bootstrap 5 + Custom CSS (dark theme)
- **Interactions:** Vanilla JS

## Quick Start

```bash
npm install
npm start
# Visit http://localhost:3000
```

## Deploy on Render

Push to `main` on GitHub → connect repo on [render.com](https://render.com) → auto-deploy via `render.yaml`.

See [CLAUDE.md](./CLAUDE.md) for full update and deployment guide.
